## Como executar o projeto

Clone o repositório:

```bash
git clone https://github.com/marianoxzz001/porfolioEduardo.git
```

Entre na pasta:

```bash
cd porfolioEduardo
```

Instale as dependências:

```bash
npm install
```

Inicie o projeto:

```bash
npm run dev
```

Acesse o endereço exibido no terminal, normalmente `http://localhost:5173`.
